# MT5 Test Matrix

## 目的

EMA押し目EAと水平線ブレイクEAを、同じ条件で比較するためのテスト表です。

まず「安全に止まるか」を確認し、その後に「成績を見る」順番にします。

## 共通テスト

| No | テスト | 期待結果 |
| --- | --- | --- |
| 1 | USDJPY以外のチャートに適用 | 新規エントリーしない |
| 2 | `RequireJPYAccount=true` でJPY以外の口座 | 新規エントリーしない |
| 3 | `EnableTrading=false` | `[BLOCK] EnableTrading is false.` が出る |
| 4 | `NewsStopMode=true` | 新規エントリーしない |
| 5 | 稼働時間外 | 新規エントリーしない |
| 6 | `MaxSpreadPips` を極端に低くする | スプレッド超過で止まる |
| 7 | スプレッド超過後に通常値へ戻す | `SpreadCooldownMinutes` 中は止まる |
| 8 | 既存USDJPYポジションあり | 新規エントリーしない |
| 9 | `MaxTradesPerDay=1` | 1日1回で止まる |
| 10 | `MaxConsecutiveLossesPerDay=1` | 1敗後に当日停止する |
| 11 | `DailyLossLimitJPY` を小さくする | 日次損失到達で止まる |
| 12 | 金曜23時以降 | 新規エントリーしない |
| 13 | 金曜23時以降に保有あり | EA管理ポジションだけ決済する |
| 14 | `MaxHoldingMinutes` を短くする | 時間超過で成行決済する |
| 15 | `EmergencyFloatingLossLimitJPY` を小さくする | 含み損到達でEA管理ポジションだけ決済する |

## 成績比較

結果は `backtest_results_template.csv` に同じ形式で記録します。

比較時は、以下の順番で見ます。

1. 最大ドローダウン
2. 最大連敗
3. 月別損益の安定性
4. プロフィットファクター
5. 取引回数
6. 勝率

利益額だけで採用しないでください。
