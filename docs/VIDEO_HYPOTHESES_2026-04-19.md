## What Looks Actually Useful

### 1. ナイト込みチャートを優先する

- 戦略①では、日中足だけよりもナイトセッション込みのチャートの方が、より広い時間帯の値動きを把握しやすいという話が中心だった。
- これは今の研究と相性がいい。
- 既存の `prev_night_up` や `prev_night_down` の発想と整合している。

採用方針:
- 今後の新規ルールでは、日中寄り付き系でも `前夜の方向` と `前夜の値幅` を基本説明変数として優先する。

### 2. 板の枚数そのものをシグナルにしない

- 戦略①では、板の数量は一瞬で変わるため、数量の多い少ないだけで判断しない方がいいと説明されていた。
- これはかなり大事。
- もし今後板データを使うとしても、単純な「売り板が厚いから下」みたいなロジックは危険。

採用方針:
- 板枚数の瞬間値は戦略シグナルに採用しない。
- 使うなら約定ベースや持続時間つきの圧力指標に限定する。

### 3. まず相場シナリオを分けてから戦略を当てる

- 戦略②と「厳選6選」では、上がる・下がる・動かない・大きく動く・IVが上がる・IVが下がる、というシナリオ分けが中心だった。
- この考え方自体はかなり使える。
- 今の研究も、実質は `midday long`, `morning short`, `night short`, `opening fade` とシナリオ分けになっている。

採用方針:
- 新ルールは「万能1本」を探すより、`上昇局面`, `下落局面`, `レンジ局面`, `大変動局面` の役割分担で追加する。

### 4. レンジ相場と大変動相場を別ルールで扱う

- 「厳選6選」では、相場が動かない時と大きく動く時は、方向性の当て方ではなく、別の戦い方をするという整理だった。
- 先物単独研究でも、この考え方はかなり価値がある。

研究仮説:
- `opening fade` はレンジ寄りの局面限定ルールとして強化する。
- `breakout` 系は「大きく動く日」専用に絞ると利益効率が上がる可能性がある。

### 5. 事前ロスカットの固定は必須

- 戦略①でかなり明確に「ロスカット水準をあらかじめ決めておく」と言っている。
- 当たり前に見えて、今の研究でもここをもっと攻める余地がある。

採用方針:
- 次の攻め枝では、ロット増加より先に `ルール別の固定損失上限` を明示して比べる。

## Research Branches To Add

### A. Regime Split Branch

狙い:
- 既存ルールを、`動かない日` と `大きく動く日` で分岐させる。

具体案:
- `prev_session_realized_range`
- `night_range`
- `opening_range`
- `vix_change`

で日を分類して、
- レンジ寄りなら `fade`
- トレンド寄りなら `breakout`

へ振り分ける。

### B. Event Filter Branch

狙い:
- 戦略②の説明では、日銀会合のようなイベント日で先物の方向性を取りに行く例が使われていた。
- そのまま裁量再現はしないが、イベント日が歪みやすいという発想は使える。

具体案:
- `BoJ day`
- `FOMC day`
- `CPI day`

では
- 新規停止
- breakoutのみ許可
- fadeのみ停止

のような軽いフィルタを試す。

### C. Hedge Overlay Branch

狙い:
- 戦略③と守屋動画の共通点は、先物を方向当てではなくヘッジにも使うこと。

具体案:
- 将来の別ラインとして `equity-hedge mode` を作る。
- これは今の主研究ではなく、運用拡張候補として保持する。

## What Not To Do

- 動画内の個別事例をそのまま売買ルールにしない。
- 板の厚さだけで売買判断しない。
- 会合イベントの方向性予想を裁量のままコード化しない。
- オプション前提の話を、先物単独ルールへそのまま移植しない。

## Immediate Next Tests

今すぐ研究に落とせる順番はこれ。

1. `regime split` として、`opening fade` を低ボラ日限定で再検証
2. `breakout` 系を高ボラ日限定で再検証
3. `BoJ / CPI / FOMC` のイベント日フィルタ候補を追加

## Decision

- 動画からの知識流入は有効。
- ただし「手法をそのままコピー」ではなく、「相場の分け方」と「使ってはいけない情報」を学ぶ用途が中心。
- 研究の次の一手としては、`regime split` が一番有望。
